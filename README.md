## 🌟 Features

- **Read-Only Reference:** Quick access to breakfast, lunch, dinner, and snack options.
- **Food Database & Alternatives:** Comprehensive tables showing exact equivalent portions for starches, fruits, fats, and meats.
- **Integrated AI Assistant:** A built-in chat interface powered by the Gemini API to answer specific diet questions and evaluate meals.
- **No Tracking Required:** Built specifically to eliminate the stress of daily calorie counting and meal recording.
- **Responsive Design:** Optimized for mobile devices with seamless scrolling and a native app feel.
- **Theme Support:** Includes both Light and Dark modes.

---

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** Vanilla CSS3
- **Logic:** Vanilla JavaScript
- **AI Integration:** Google Gemini API

---

## 🏗️ Architecture

This project uses a **single-file architecture**, where all HTML, CSS, and JavaScript are bundled together for maximum portability and fast loading.

---

## 🚀 Usage

To use the AI Assistant feature, you'll need a Gemini API key.

1. Open the application.
2. Go to **Settings (الإعدادات)**.
3. Paste your Gemini API key into the designated field.
4. Open the AI chat and start asking questions about your diet.

---
